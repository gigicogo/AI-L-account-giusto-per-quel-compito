# Esercitazione — L’account giusto per quel compito

Web app statica, senza librerie esterne, database, analytics o connessioni a servizi esterni.



## Uso didattico

Tempo previsto: 8–10 minuti. Tre scenari, scelte `PROCEDO / ADATTO / MI FERMO / CHIEDO`, motivazione facoltativa, feedback dopo ogni risposta e riepilogo stampabile/esportabile in TXT.

La app non invia le risposte a server e non le conserva tra sessioni. Consiglia ai partecipanti di usare solo motivazioni generiche, mai dati personali o pratiche autentiche.

## Aggiornare i casi

Nel file `index.html`, nella sezione JavaScript, modifica l'array `cases`: titolo, scenario, scelta `correct`, spiegazione e punti di controllo. Non serve alcuna compilazione.
